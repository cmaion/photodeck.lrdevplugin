# PhotoDeck Publish Plugin for Lightroom

Publish photos and manage PhotoDeck galleries from Adobe Lightroom Classic on
Windows or macOS. Available in English, French and German.

## Getting started

1. Get the [official plugin from PhotoDeck](https://www.photodeck.com/lightroom/), then add it in Lightroom under
   **File > Plug-in Manager > Add**.
2. In the Publishing Manager, click **Connect / Reconnect** and authorize access
   in your system browser. Passwords and two-factor codes are entered only on
   PhotoDeck, never in the plugin.
3. Return to Lightroom and choose your website and media library.

Credentials are stored securely and renewed automatically. Use **Connect /
Reconnect** if prompted, or **Disconnect** to revoke access. You can also revoke
access under PhotoDeck's **Connected apps**.

## Galleries

Create and maintain galleries and folders from Lightroom, or import your existing
PhotoDeck gallery structure. Photos not published by this plugin do not appear
automatically in Lightroom; importing gallery structure does not import its media.
